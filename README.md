# akshay-thkur.github.io

Personal academic website of Akshay Thakur (PhD candidate, Aerospace & Mechanical Engineering, University of Notre Dame).

Live at **https://akshay-thkur.github.io**

## Structure

```
index.html            the whole site (styles + scripts inline)
CurriculumVitae.pdf   linked from the "cv" nav item
assets/               profile photo and project figures
```

## Editing

- **Publications / talks**: edit the `PUBS` array near the bottom of `index.html`.
- **Projects, experience, recent**: plain HTML sections in `index.html`.
- **CV**: replace `CurriculumVitae.pdf` (keep the filename).
